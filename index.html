🛠 사용 방법

수업 중 함께, 또는 집에서 혼자 연습할 때

🔊 원어민 음성

모든 예문·질문·모범답안의 ▶ 버튼을 누르면 미국·영국 원어민 스타일의 자연스러운 음성이 재생됩니다. 한 번 더 누르면 멈춥니다.

⏱ 실전 타이머 + 녹음

[시작]을 누르면 실제 시험처럼 준비 시간 → 신호음 → 답변 시간이 진행되고, 내 목소리가 녹음·자동 받아쓰기 됩니다. (Chrome/Edge + 마이크 권장)

✅ 자동 채점

객관식·빈칸·문장 배열·끊어 읽기는 정답과 점수가 즉시 나오고, 말하기는 정확도·핵심 표현·답변 길이로 예상 점수를 보여 줍니다.

✍ 마이크가 없다면

답변 칸에 영어로 직접 입력한 뒤 [채점하기]를 누르면 같은 방식으로 채점됩니다. 모범답안과 해석도 언제든 확인할 수 있어요.

※ 이 사이트의 지문·문항·모범답안은 시중 교재의 학습 순서와 유형을 참고하여 수업용으로 새로 작성·변형한 것입니다.
