# TOEIC Speaking START · 인터랙티브 학습 사이트

국제학교 TOEIC Speaking 수업용 인터랙티브 사이트입니다.

- **메인 페이지**: `index.html` — 전체 챕터, 시험 구성, 진행률
- **챕터**: 필수 문법 20 · Part 1 지문 읽기 · Part 2 사진 묘사 · Part 3 질문 답하기 · Part 4 표 보고 답하기 · Part 5 해결책 제안(구 유형) · Part 6 의견 제시 · 실전 모의고사 1–3
- **기능**: 원어민 음성(▶), 실전 타이머(준비→답변), 녹음·자동 받아쓰기(Chrome/Edge), 객관식·빈칸·문장 배열·끊어 읽기 자동 채점, 말하기 예상 점수, 모범답안·해석
- 진행률과 점수는 각 학생의 브라우저(localStorage)에 저장됩니다.

## 구조
```
index.html            메인
grammar.html ...      챕터 페이지 (data/<id>.js 를 읽어 렌더링)
assets/app.js         공통 엔진 (문항 렌더링·채점·타이머·녹음)
assets/style.css      디자인
data/*.js             챕터별 문항 데이터
audio/*.mp3           원어민 음성 (파일명 = 음성코드|문장 해시)
img/*.svg             사진 묘사용 일러스트
```

※ 지문·문항·모범답안은 시중 교재의 학습 순서와 유형을 참고해 수업용으로 새로 작성·변형했습니다. 사진 묘사용 그림은 직접 제작한 일러스트입니다.
